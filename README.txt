Готовый демо-сайт репетитора по английскому языку.

Как открыть:
1. Откройте файл index.html в браузере.
2. Все стили и JavaScript уже находятся внутри файла — отдельные зависимости не нужны.

Что обязательно заменить перед публикацией:
- имя преподавателя (Александра Костина);
- фотографию;
- описание опыта и образования;
- реальные цены;
- реальные отзывы;
- реальные контакты;
- политику обработки персональных данных;
- подключение формы к Telegram/CRM/почте.

Макет рассчитан на школьников 1–11 класса и подготовку к ОГЭ/ЕГЭ.

Дополнительно:
- в папку assets добавлена иллюстрация tower-bridge.png для декоративного блока.
