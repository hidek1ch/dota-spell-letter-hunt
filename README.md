# Dota 2 Spell Letter Hunt — multiplayer

Первая онлайн-версия мини-игры на базе исходного HTML.

## Что уже есть

- Комнаты по пятизначному коду.
- Хост — отдельная роль: только он получает секретную способность, героя, иконку и три буквы.
- Игроки по очереди угадывают; им секретные данные сервер вообще не отправляет.
- Серверный таймер 5:00, общий для всех устройств.
- Счёт, очередь, пауза, пропуск, завершение матча и переподключение после обновления страницы.
- Способности берутся сервером из актуального `odota/dotaconstants`: обычные способности, пассивки, innate и дополнительные hero abilities попадают в общий пул; технические hidden/helper abilities отфильтровываются.
- Колода перемешивается: одна и та же способность не повторяется до исчерпания пула; по возможности подряд не идёт один герой.
- Хост может настроить допустимые русские буквы. По умолчанию включён более удобный игровой набор; финальный набор можно поменять позже.
- В коде уже оставлены места для будущих «бонусов/штрафов» и «особенных раундов», но они пока выключены.

## Запуск

Требуется Node.js 18+.

```bash
npm install
npm start
```

После запуска сайт доступен на `http://localhost:3000`.

## Деплой

Проект готов к обычному Node-хостингу. Есть `Dockerfile` и `render.yaml`; переменная `PORT` поддерживается автоматически.

## Важно про базу Dota 2

Сервер пытается загрузить полный актуальный реестр через jsDelivr, OpenDota и GitHub Raw. В отличие от старого одиночного HTML, запрос идёт с сервера, поэтому браузерный CORS больше не должен обрезать базу до аварийного пула. Если все внешние источники недоступны, включается небольшой встроенный fallback и это видно по счётчику базы в интерфейсе.
